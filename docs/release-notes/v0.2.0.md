# imagebuilder v0.2.0

## Highlights

- Added provider-neutral `source.marketplaceRef` support across the remote build pipeline.
- Added marketplace/source resolution for Azure, AWS, OpenStack/Open Telekom Cloud, and vSphere.
- Added ArgoCD-ready Ubuntu 24.04 examples for AWS, Open Telekom Cloud, and vSphere.
- Added vSphere Content Library support for marketplace mappings.

## Provider Changes

- Azure can now build remote images directly from marketplace image references.
- AWS can resolve marketplace references to AMIs through EC2 image discovery; the Canonical Ubuntu 24.04 mapping is the shipped example used by the Ubuntu 24.04 ArgoCD sample, not a CRD-level Ubuntu-only model.
- OpenStack can resolve marketplace references by searching active public Glance images; the Open Telekom Cloud Ubuntu 24.04 resources are an example that avoids hard-coding an image ID.
- vSphere can map marketplace references to VM/template references, Content Library item paths, or Content Library item IDs.

## GitOps Examples

- Updated Azure and AWS Tomcat examples to use `source.marketplaceRef`.
- Added `examples/argocd/aws-ubuntu24-resources`.
- Added `examples/argocd/open-telekom-cloud-ubuntu24-resources`.
- Added `examples/argocd/vsphere-ubuntu24-resources`.
- Updated vSphere Tomcat examples to use Content Library backed marketplace mapping.
