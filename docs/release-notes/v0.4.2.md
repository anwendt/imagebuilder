# imagebuilder v0.4.2

## Highlights

- Fixes the container image security scan findings from the `v0.4.1` release
  line.
- Updates the Go toolchain used by all builder stages to `1.26.5`.
- Updates security-sensitive Go dependencies used by the operator and provider
  binaries.
- Updates Helm chart defaults and installation examples for the `v0.4.2`
  release line.

## Security

- Updated all Go builder stages from `golang:1.26.4-alpine` to the pinned
  `golang:1.26.5-alpine` digest.
- Updated `google.golang.org/grpc` from `v1.81.1` to `v1.82.1`.
- Updated `golang.org/x/text` from `v0.37.0` to `v0.39.0`.
- Updated related `golang.org/x/*` modules resolved by `go mod tidy`.
- Regenerated `NOTICE` for the updated module graph.

## Helm And Installation

- Updated `charts/imagebuilder/Chart.yaml` to `0.4.2`.
- Updated operator, builder, uploader, and provisioner default image tags to
  `v0.4.2`.
- Updated quickstart and operations examples to install chart version `0.4.2`.
