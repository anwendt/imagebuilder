# imagebuilder v0.4.1

## Highlights

- Ships provisioner-specific OCI images with the matching runtime binaries
  preinstalled.
- Documents the default provisioner image contents in the README, architecture
  guide, and operator operations guide.
- Updates the Helm chart and default image tags for the `v0.4.1` release line.

## Provisioner Images

- `imagebuilder-provisioner-ansible` now contains `ansible-playbook`.
- `imagebuilder-provisioner-chef` now contains `chef-client` and `chef-apply`.
- `imagebuilder-provisioner-puppet` now contains `puppet`.
- `imagebuilder-provisioner-saltstack` now contains `salt-call` and
  `salt-minion`.
- `imagebuilder-provisioner-custom` remains a lightweight base image with the
  Image Builder provisioner runner and base OS tools.

This removes the need to install the selected provisioner runtime at execution
time for the released default provisioner images. Custom images are still
supported per `VMImage` for pinned toolchains, internal modules, cookbooks,
states, collections, or organisation-specific bootstrap tooling.

## Helm And Installation

- Updated `charts/imagebuilder/Chart.yaml` to `0.4.1`.
- Updated operator, builder, uploader, and provisioner default image tags to
  `v0.4.1`.
- Updated quickstart and operations examples to install chart version `0.4.1`.

## Validation

- Built local provisioner images for `ansible`, `chef`, `custom`, `puppet`, and
  `saltstack`.
- Verified the expected runtime binaries inside the built provisioner images:
  `ansible-playbook`, `chef-client`, `chef-apply`, `puppet`, and `salt-call`.
