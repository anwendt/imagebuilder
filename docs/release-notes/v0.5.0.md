# imagebuilder v0.5.0

## Highlights

- Adds a production-capable GCP image provider alongside AWS, Azure,
  OpenStack, and vSphere.
- Streams image delivery directly to providers and supports resumable upload
  sessions for large artifacts.
- Adds declarative rebuild revisions and durable recovery across controller,
  upload, and cleanup restarts.
- Introduces signed VM image evidence for secure Azure remote builds.
- Strengthens provider isolation, scoped operation, Kubernetes compatibility,
  and supply-chain controls.

## Image Delivery And Providers

- Added GCP image import, GCE archive generation, resumable uploads, provider
  samples, documentation, and a signed multi-architecture provider image.
- Added streaming provider uploads over gRPC to avoid staging complete images
  in uploader memory or local storage.
- Added resumable sessions for AWS, Azure, GCP, OpenStack, and vSphere upload
  paths, with durable operation state and retry-safe recovery.
- Added explicit transient provider error classification and retry handling.
- Aligned the provider gRPC port contract and hardened multi-architecture
  provider builds.

## Reconciliation And Security

- Added immutable rebuild revisions for declarative VM image rebuilds.
- Preserved in-progress build, upload, registration, and cleanup operations
  across controller restarts.
- Added an evidence contract and example evidence provisioner for signed build
  metadata and attestations.
- Added fail-closed provider selection, digest and signature enforcement,
  namespace-scoped RBAC, network boundaries, and uncached reads for sensitive
  resources.
- Enforced the Kubernetes version boundary required for restartable init
  containers and delegated build placement to the Kubernetes scheduler.

## Security Maintenance

- Updated all Go build stages to the pinned Go `1.26.6` Alpine image.
- Updated `github.com/go-git/go-git/v5` to `v5.19.2`.
- Migrated GCP credentials to the current Google Cloud authentication API and
  restricted JSON credentials to service-account documents.
- Added an explicit S3 multipart part-number bound before integer conversion.
- Regenerated `NOTICE` for the current dependency graph.

## Helm And Installation

- Updated `charts/imagebuilder/Chart.yaml` to `0.5.0`.
- Updated operator, builder, uploader, and provisioner default image tags to
  `v0.5.0`.
- Packages the Helm release with the exact digests produced and signed by the
  release workflow.
- Updated quickstart and operations examples to install chart version `0.5.0`.

## Validation

- Full Linux unit, core E2E, manifest, and vSphere simulator test suites.
- Generated-artifact, Helm lint, and Helm render gates.
- `go vet`, `staticcheck`, `gosec`, `govulncheck`, license, and gitleaks gates.
- Trivy HIGH/CRITICAL scans for the operator, builder, uploader, AWS, Azure,
  GCP, OpenStack, and vSphere images.
- CodeQL and dependency graph analysis.
