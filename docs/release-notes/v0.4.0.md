# imagebuilder v0.4.0

## Highlights

- Publishes the Helm chart as an OCI artifact to GHCR from the core release workflow.
- Adds a low-friction Helm development profile for local clusters.
- Makes Kyverno image signature policy rendering opt-in instead of a default requirement.
- Simplifies the quickstart around the published Helm chart.
- Adds concrete Git-backed shell provisioner documentation and examples.

## Helm And Installation

- The `Core Images Release` workflow now packages and pushes the chart to
  `oci://ghcr.io/anwendt/charts/imagebuilder` for SemVer release tags.
- Added `make helm-package`, `make helm-push`, and `make helm-template-dev`.
- Updated chart metadata and default image tags for the `v0.4.0` release line.
- Added `charts/imagebuilder/values-development.yaml` for local clusters. The
  profile uses one operator replica and disables webhooks, cert-manager
  integration, NetworkPolicies, namespace quotas, strict provider mTLS, digest,
  and signature requirements.

## Policy Defaults

- `imageSignaturePolicy.enabled` now defaults to `false` so the chart installs
  on clusters without Kyverno CRDs.
- The optional Kyverno policy can still be enabled with
  `--set imageSignaturePolicy.enabled=true`.
- The Helm values schema now allows documented development overrides while
  keeping production-oriented defaults in `values.yaml`.

## Git Provisioner Examples

- Added `docs/user-guide/git-provisioners.md`.
- Added `examples/provisioner-git-repo/` with ordered shell scripts:
  - `10-basic-tools.sh`
  - `20-hardening.sh`
  - `30-monitoring.sh`
- Updated the quickstart and VMImage authoring guide to show Git directory
  expansion for shell provisioners.
- Replaced token-like documentation placeholders with environment-variable
  placeholders to avoid false positive secret findings.

## Documentation

- Added a short Quick Install section to the repository README.
- Split quickstart installation guidance into production-like and development
  Helm paths.
- Documented optional Kyverno usage and the development chart profile in the
  operator and production-readiness guides.

## Validation

- `make helm-lint`
- `make helm-template`
- `make helm-template-dev`
- `helm lint charts/imagebuilder -f charts/imagebuilder/values-development.yaml`
- `bash -n examples/provisioner-git-repo/scripts/ubuntu/*.sh`
- YAML parse validation for `config/samples/vmimage-ubuntu-git-provisioners.yaml`
