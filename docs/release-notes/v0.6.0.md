# imagebuilder v0.6.0

## Highlights

- ADR-011: VM image evidence is collected in the guest, retrieved by the
  provider and published and signed by the controller. It works on Azure and
  now also on vSphere.
- VM image descriptors are signed with the ImageFactory cosign key and carry
  SLSA provenance, CycloneDX SBOM and Trivy report as cosign v3 attestations,
  the same format as container images.
- One OCI index per logical image version collects the descriptors of all
  platforms.
- Opt-in verify boot: the published Azure gallery version or vSphere template
  boots once with platform-style user-data before the build is reported Done.

## API (additive)

- `spec.evidence.publisher: provider|controller` (default `provider`, ADR-008
  unchanged), `spec.evidence.subject {name, version, platform}`, and
  `sbomFormat: cyclonedx-json`.
- `status.evidence.descriptorRef`, `indexRef`, `publisher`, `bundleDigest` and
  `publishJobRef`.
- Admission for `publisher: controller`: remote mode, a complete subject, exactly
  one evidence provisioner (later provisioners allowed) and no credentials on the
  evidence provisioner.
- Provider protocol (additive): `RemoteBuildResponse.evidence_bundle`,
  `RemoteEvidencePolicy.publisher`/`subject`, and
  `RemoteBuildRequest.evidence_bundle_acknowledged`/`image_version`.

## Providers

- vSphere: evidence outbox retrieval through Guest Operations file transfer,
  bundle persistence on the provider volume, `remote.verifyBoot` (deploys from the
  Content Library template with Aria-style vApp `user-data`).
- Azure: evidence outbox upload through a 15-minute write-only SAS for a single
  blob (shared key or user delegation), proxy fallback, SAS redaction, and
  `remote.verifyBoot` (VM from the gallery version with customData).
- Azure: `galleryVersion` falls back to `spec.evidence.subject.version` or the
  `imagebuilder.io/image-version` annotation.

## Operator And Chart

- New `evidencePublisher` chart values and `--evidence-*` flags, disabled by
  default; namespaced Role and NetworkPolicy for the publication Job.
- Publication Job: digest-pinned ORAS v1.3.0 and Cosign images, non-root,
  read-only root filesystem, no service account token.
- The operator receives `IMAGEBUILDER_VERSION` (chart `appVersion`).
- `hack/evidence-publication-e2e.sh` runs the publication steps against a local
  registry; `examples/evidence/ubuntu-evidence.sh` is a reference collector.

## Upgrade Notes

- No change is needed for existing VMImages: `publisher` defaults to `provider`.
- To use the controller publisher, set `evidencePublisher.enabled: true`, provide a
  registry push Secret and the ImageFactory cosign key Secret in the operator
  namespace, and update the PlatformProvider images (azure, vsphere) to v0.6.0.
